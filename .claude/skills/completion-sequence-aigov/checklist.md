# Post-Change Completion Checklist

## Code changes

1. Run tests — full test suite
2. Code review if substantial
3. Update _ai-context/SESSION-STATE.md (version, counts, summary)
4. Commit and push
5. Verify CI green

## Content changes

1. Run tests — full test suite
2. Update _ai-context/SESSION-STATE.md
3. Commit and push

## Documentation-only changes

1. Update _ai-context/SESSION-STATE.md if applicable
2. Commit and push
